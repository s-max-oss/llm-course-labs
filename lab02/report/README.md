`sample_analysis.json` 是报告5.2节的补充分析：键 `0`、`100`、`199` 对应测试样本索引；`positions` 为各帧球心坐标（x、y），`speed` 为速度向量模长（像素/帧），`hits` 标记到达该帧时是否反弹。`mse` 使用组合第1次复测保存的未裁剪预测计算。`bounce_target` 按第4帧至第5帧是否反弹对全部200个测试样本分组；这是描述性比较，未控制速度和位置因素。
