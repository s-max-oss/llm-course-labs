# 实验三实施方案

依据课程《作业三 手搓最小LLM 使用CPU训练 实验指南》。用户已补充报告模板，并要求先交付代码；本阶段完成实现、实验及原始素材，正式报告后续填写。沿用已确认的 Codex 协作工具，真实记录提问与操作。

## 分段理解

1. 数据与分词：指南内置古诗片段原样提取为 `corpus.txt`，按字符排序建立词表。输入窗口 `x=data[i:i+T]`，标签 `y=data[i+1:i+T+1]`。每个位置学习预测它后面的一个字符。
2. 注意力：`(B,T,C)` 经一次线性层得到 Q/K/V，拆成 `(B,H,T,C/H)`。`QKᵀ/sqrt(C/H)` 得到 `(B,H,T,T)`，上三角填负无穷，使模型看不到未来字符。softmax 后乘 V，再拼回 `(B,T,C)`。
3. 模型：词嵌入与位置嵌入相加；两层 Pre-Norm 注意力/MLP 残差块；最终 LayerNorm 后映射到词表。输出权重与词嵌入使用同一个 Parameter，不能重复计数。
4. 训练：CPU，AdamW，默认权重衰减0.01，batch32，种子42。记录每一步训练交叉熵、固定训练窗口评估、纯训练耗时和真实生成文本。指南没有留出测试集，这些 loss 只能说明语料拟合，不能代表泛化。
5. 采样：只取最后位置的 logits，除以温度，截取 top-k，概率采样后把字符接回输入。独立采样随机数，不干扰训练批次。

## 控制变量方案

| 编号 | 改动 | 训练步数 |
|---|---|---:|
| baseline | L2/C128/H4/T128/lr0.001，有位置编码 | 2000 |
| baseline_1000 | 同一基线运行在第1000步保存快照 | 1000 |
| exp1_lr_high / exp1_lr_low | lr0.01 / lr0.0001 | 各1000 |
| exp2_shallow / exp2_deep | 层数1 / 4 | 各1000 |
| exp3_small / exp3_large | C64/H2 / C256/H8 | 各1000 |
| exp4_short | 上下文32 | 1000 |
| exp5_no_pos | 移除位置编码 | 1000 |
| exp6 | 固定最终基线，温度0.5/1.0/1.5，top-k20 | 不训练 |

嵌入维度实验按指南同时调整头数，保持每头32维；这一维度并非只更改一个配置字段。短上下文实验每步处理的字符数也下降，分析同时报告这一计算预算差异。

采样补充 top-k5 和不截断，5组均用「春、月、山」三个固定提示词、相同随机种子列表，各生成200字符；基线另提供「春、月」各2段。选做采用禁止重复3-gram，与无惩罚使用相同模型、提示和种子比较。质量星级按公开文字标准评阅原始生成，明确属于主观评价。

## 参数量

近似：`V*C + T*C + L*12*C²`。

精确：`V*C + (T*C if use_pos else 0) + L*(12*C²+13*C) + 2*C`。

每层额外13C来自注意力4C偏置、MLP5C偏置、两处LayerNorm的4C；最终LayerNorm为2C。参数与初始loss均以实际词表为准。
